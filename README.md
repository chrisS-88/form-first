# Form First

Form First is a simple, guided multi‑step booking flow demo built with Astro, React, and the Pennine Design System.  
It’s designed to show how a clean, modern, form‑first experience can feel when it’s intentionally structured, minimal, and user‑friendly.

This project is not a full product — it’s a demo that focuses on UX, flow, and component structure rather than backend logic.

---

## Features

- Multi‑step booking flow with a clear, guided structure
- Lightweight, modern UI built with the Pennine Design System
- Lookup Booking page (demo‑only, using mock data)
- Simple Admin view for exploring the data model
- Clean, minimal navigation and layout
- Fully responsive and fast by default thanks to Astro

---

## Why this exists

This demo was created to show how a form‑first approach can improve clarity and reduce friction in booking experiences.  
It’s intentionally simple — no backend, no authentication, no database — just a clean UX that demonstrates how a real system _could_ feel.

---

## Tech Stack

- **Astro** — for fast, content‑focused pages
- **React** — for interactive components inside the booking flow
- **Tailwind CSS** — for styling
- **Pennine Design System** — custom UI patterns and tokens
- **Mock data** — used for lookup and admin pages
